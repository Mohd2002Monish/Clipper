# Absolute Ban on Emojis

- **NEVER use any emoji in any website, UI component, page, label, button, modal, toast, placeholder, or copywriting.**
- No emoji characters (e.g. 🚀, 🌅, ☀️, 🌙, 🦉, 👇, 🎬, 🔥, 👍, etc.) are permitted anywhere.
- Always use professional SVG icons (such as Lucide React icons) or clean typography badges instead.
