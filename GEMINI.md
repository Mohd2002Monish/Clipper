# Project & UI Rules for Antigravity

## Critical Rule: Absolute Ban on Emojis (Never Use Any Emojis)
- **NEVER use any emoji in any website, UI component, page, label, button, modal, toast, placeholder, or copywriting.**
- This rule is strict and absolute: no emoji characters (e.g. 🚀, 🌅, ☀️, 🌙, 🦉, 👇, 🎬, 🔥, 👍, etc.) are allowed anywhere in the codebase, markup, or user interface.
- Always use professional SVG icons (such as Lucide React icons like `<Sunrise />`, `<Sun />`, `<Moon />`, `<Sparkles />`, `<CheckCircle2 />`, `<AlertCircle />`, `<Eye />`) or clean typography badges instead.
- This applies globally to all current and future frontend code, pages, and components.
